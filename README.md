# ChameleonGuI-beautify

基于 [GameTec-live/ChameleonUltraGUI](https://github.com/GameTec-live/ChameleonUltraGUI) 的二次开发：为 Chameleon Ultra 的 Flutter 图形客户端换上 iOS 26 风格的液态玻璃（Liquid Glass）UI。

上游应用本身功能未动，本项目只做界面与交互的美化改造：整套玻璃材质组件、液态手感的导航栏、可滑动的选中透镜、真毛玻璃弹窗与下拉，以及一轮完整的汉化补齐。每个迭代版本的 APK 安装包都发布在本仓库的 [Releases](../../releases) 中。

## 改了什么

- **液态玻璃导航栏**：左侧导航面板是一整块真液态玻璃（饱和→模糊管线、边缘光、漂移流光、厚度层次），拖动时宽度实时跟手、过拉有橡皮筋阻尼、松手由物理弹簧收放；v2.15 起改为常开布局＋裁剪显隐，过渡全程零重排版、零组件重挂载，图标位置纹丝不动。
- **可滑动的液态玻璃透镜**：选中指示不再是框架的逐项淡入淡出，而是一颗自绘玻璃透镜在导航项之间滑行：高速时沿运动方向拉伸、带选中图标 ×1.2 放大，收起时是小圆角矩形，展开时拉长为整行胶囊；支持竖直拖动擦选，松手吸附到最近的可用项。
- **卡片与弹窗真毛玻璃**：全 App 的对话框、卡片按钮统一为带真实背景模糊的磨砂玻璃；状态栏与标题栏全透明，背景一透到底，不再有顶部分界色带。
- **设置页自绘毛玻璃下拉**：主题颜色与语言两个下拉换成自绘组件，弹出面板与卡片详情对话框同款光学（真实模糊、细亮边、圆角），选中行高亮、长列表可滚动。
- **深色主题中性化修复**：修复深色主题下卡片磁贴被染成饱和红色的问题——根源是互补色表把强度编码在 alpha 通道里而改版样式覆盖了它；深色下改为中性玻璃填充，浅色保持原有粉彩。
- **主题色跟随的玻璃染色**：导航面板的玻璃底色由当前配色方案主色粉彩化后染入，色相随主题色与明暗走，但永远保持低饱和，不会变成色块。
- **色差接缝消除**：页面染色层改为全屏铺设，消除了侧边栏右侧那条从顶到底的色差边界线，整屏色调统一。
- **全量中文汉化补齐**：补齐 175 条缺失的中文翻译（插件系统、Gen4 工具、值块工具等），并把 NDEF 编辑器等 29 处硬编码英文接入本地化。
- **不对称手势**：右滑展开保留阈值（拖过约三成或甩速达标才展开），左滑收起无阈值——只要有向左滑的操作就直接收回；点任意图标也会弹簧收回。

## 下载与安装

到本仓库的 [Releases](../../releases) 页面下载对应版本的 APK 安装。

- 系统要求：Android 7.0（API 24）及以上
- 包名：`io.chameleon.ultra`，应用版本 1.4.0（各二开版本的差异以 Release 标注的 v1…v2.16 区分）
- **签名说明：所有 APK 均为调试签名（非官方发布签名）**，可正常安装使用，但请知悉其来源为个人二开构建。

### ⚠️ 安装顺序警告（签名证书变更）

各版本签名证书不一致，跨版本安装请注意：

- **v1**：如已安装官方版，需先卸载官方版再安装。
- **v1.1**：签名与 v1 不同，需先卸载 v1 再安装（v1.2–v2.1 与 v1.1 同证书，可在其上直接覆盖）。
- **v2.2 起更换了签名证书**：从 v2.1 及更早版本升级到 v2.2 或更新版本时，**必须先卸载旧版再安装，卸载会清除应用数据**，建议先在旧版里导出设置、装好后再导入。
- **v2.2 起各版本同证书**，v2.2 → v2.3 → … → v2.16 之间可直接覆盖安装，数据保留。

## 构建

Flutter 工程位于 `chameleonultragui/` 子目录：

```bash
cd chameleonultragui
flutter build apk --release
```
